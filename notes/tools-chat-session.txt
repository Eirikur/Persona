  ## Claude Code Session Transcript Saving — Concrete Options

  ### Built-in Solution (Recommended)
  **`/export` slash command** in interactive mode:
  - Run `/export ~/my-transcript.txt` to save the full conversation as readable
  plain text
  - Or run `/export` alone to open a menu (copy to clipboard or save to file)
  - Includes all messages, tool outputs rendered as text (not raw JSONL)
  - Directly searchable and grep-able afterward

  ### Non-Interactive / Scripted Use
  For `claude -p` runs, use output redirection:

  **Plain text output (default):**
  ```bash
  claude -p "your prompt" > output.txt
  ```

  **Structured JSON (includes metadata like cost, session ID):**
  ```bash
  claude -p "your prompt" --output-format json > session.json
  jq -r '.result' session.json  # extract readable text
  ```

  **Streaming JSON (tokens as they arrive):**
  ```bash
  claude -p "your prompt" --output-format stream-json --verbose | tee
  session.log
  ```

  ### Raw Transcript Files (Not Recommended)
  Claude Code stores sessions as JSONL at
  `~/.claude/projects/<project-name>/<session-id>.jsonl`. Documentation
  explicitly warns parsing these directly can break between versions—use
  `/export` or JSON output above instead.

  ### Terminal-Level Fallbacks
  If Claude Code's built-in options don't work for your case:
  - **`script` command:** `script -c 'claude' ~/session.log` (captures all
  terminal I/O)
  - **`tmux`:** `tmux capture-pane -p > output.txt` or `pipe-pane`
  - **Redirection:** `claude > session.txt 2>&1` (captures stdout/stderr)

  ### Summary
  Best answer for interactive TUI: run `/export ~/filename.txt` when done.
  Best answer for scripts: `claude -p "..." --output-format json | jq -r
  '.result' > output.txt`
  Both produce plain text that's immediately searchable.

      """Run a Brave Search query and return the top results as plain text."""

      if not api_key:

      query = args.get("query", "")
      response = httpx.get(
